# Vision

**Product:** Resource Organizer

**Version:** 1.0

**Status:** Draft

---

# Vision Statement

Resource Organizer is an AI-powered knowledge management system that helps users organize, search, and rediscover valuable resources they have saved across the internet.

Instead of relying on folders or manual categorization, the product understands the meaning of each resource and builds intelligent relationships between them, making previously forgotten knowledge easy to find again.

Our goal is not simply to store bookmarks, but to create a searchable second brain that becomes more useful as the user's library grows.

---

# Mission

To eliminate the frustration of losing valuable knowledge by building the simplest and smartest resource library powered by semantic understanding.

---

# The Problem

Modern learners save resources from many different platforms every day.

Examples include:

- GitHub repositories
- YouTube videos
- Technical blogs
- Documentation
- Reddit discussions
- Twitter/X threads
- Instagram posts
- Research papers
- Online courses

Although saving information is easy, finding it later is surprisingly difficult.

Users typically experience problems such as:

- Hundreds of browser bookmarks with no organization.
- Multiple "Watch Later" or "Read Later" lists spread across different platforms.
- Forgetting why a resource was saved.
- Searching with the wrong keywords.
- Spending time searching for resources that were already saved months earlier.
- Creating folders that quickly become outdated or too broad.

The result is a growing collection of forgotten knowledge.

---

# Our Solution

Resource Organizer provides a single place where users can save resources from any platform.

Every saved resource is enriched with metadata and semantic embeddings, allowing the system to understand its meaning instead of relying only on keywords.

Using semantic similarity, Resource Organizer can:

- Suggest related resources.
- Organize resources into topic clusters.
- Improve search quality.
- Help users rediscover forgotten information.

The system assists users without taking control away from them.

AI recommendations remain suggestions, while users always make the final decision.

---

# Product Philosophy

Resource Organizer follows five core principles.

## 1. Retrieval Before Organization

Users care more about finding information than organizing it.

The product should optimize retrieval rather than encourage complex folder structures.

---

## 2. AI Should Assist, Not Replace

Artificial intelligence should reduce manual work while keeping the user in control.

Suggestions should always be explainable and optional.

---

## 3. Every Resource Matters

Every saved resource remains part of a single master library.

Resources are never hidden because they belong to a folder or cluster.

---

## 4. Reduce Cognitive Load

Saving information should require minimal effort.

The product should automate repetitive tasks while keeping the interface simple.

---

## 5. Long-Term Value

The product should become more valuable as the user's library grows.

Every new resource improves semantic understanding and future discovery.

# Product Goals

## Primary Goal

---

## Secondary Goals

- Reduce manual organization.
- Improve search quality.

---

# Non-Goals (MVP)

The first version is intentionally focused.

It will **not** include:

- Team collaboration.
- Social features.
- AI-generated summaries.
- Browser extension.
- Mobile application.
- Full document editing.
- Knowledge graph visualization.
- Recommendation feed.

These may be explored after validating the core product.

---

# Competitive Landscape

Current solutions solve only part of the problem.

| Product | Strength | Limitation |
|---------|----------|------------|
| Browser Bookmarks | Simple | Poor organization and search |
| Notion | Flexible | High manual effort |
| Obsidian | Powerful knowledge management | Optimized for notes rather than saved links |
| Raindrop.io | Excellent bookmark manager | Limited semantic understanding |
| Pocket | Read-later experience | Focused mainly on articles |

Resource Organizer combines simple saving with AI-powered semantic understanding.

---

# Product Differentiation

Resource Organizer is different because it focuses on meaning rather than location.

Instead of asking:

> "Which folder should this go into?"

the product asks:

> "What is this resource actually about?"

Semantic understanding enables:

- Better search.
- Better recommendations.
- Better organization.
- Better rediscovery.

# Long-Term Vision

Future versions may include:

- Browser extension.
- AI-assisted search.
- Smart reminders.
- Cross-device synchronization.
- Document indexing.
- PDF understanding.
- Voice notes.
- Knowledge graph visualization.
- Personal AI assistant.

Every new capability should reinforce the core mission of helping users rediscover knowledge.

---

# Guiding Principle

Every feature should answer one question:

**Will this help users find valuable knowledge they would otherwise forget?**

If the answer is yes, it aligns with the vision.

If not, it does not belong in the product.
